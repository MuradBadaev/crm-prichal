# Причал · CRM (демо)

Демо-CRM для кафе «Причал» в Дербенте. Работает в паре с сайтом кафе ([prichal](https://github.com/MuradBadaev/prichal)).

**Что умеет:**
- **Заявки:** брони столов, доставка и праздники. Приходят с формы на сайте или добавляются вручную по звонку. Статусы «Новая → Подтверждена → Выполнена / Отменена», заметки администратора.
- **Меню:** правка блюд, цен и описаний, скрытие блюд «нет в наличии». После сохранения меню сразу меняется на сайте.
- **Гости:** база гостей собирается из заявок по номеру телефона, есть метки и заметки.
- **Статистика:** заявки по дням за 14 дней, по типам и статусам.

**Как устроено:** HTML, CSS и JS без фреймворков, серверные функции Vercel (`api/`), данные хранятся в Vercel Blob. Вход по паролю из переменной `CRM_PASSWORD`.

Демо-данные (вымышленные гости) помечены «демо» и убираются одной кнопкой.
